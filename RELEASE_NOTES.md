## v0.4.0 (Dec 12, 2025)

- **Manual transcription is now the only mode** (auto transcription mode removed).
- **Removed** `Ctrl+Shift+Enter` / `Cmd+Shift+Enter`.
- **Kept** `Ctrl+Enter` / `Cmd+Enter` as the single shortcut to submit the buffered transcript (and screenshots if enabled).
- Interviewer speech is continuously transcribed and shown as a draft, but **nothing is submitted to the model until you explicitly submit** (Ctrl/Cmd+Enter or the existing action buttons in Assistant view).
