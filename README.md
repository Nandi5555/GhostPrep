# GhostPrep

## Keyboard Shortcuts

- `Ctrl+Enter` (or `Cmd+Enter`)
  - Submits the **currently buffered transcript** (and the most recent screenshot(s) if enabled) to the AI.
  - The app **never auto-sends** audio transcripts to the model; submission is always an explicit user action.

Notes
- Audio is continuously captured and transcribed (Speaker = interviewer, Mic = you), but transcripts remain buffered until you submit.
