# GhostPrep

## Keyboard Shortcuts

- `Ctrl+Enter` (or `Cmd+Enter`)
  - Auto mode: Captures a screenshot and sends the helper prompt. Response is delivered immediately.
  - Manual mode: Captures a screenshot and sends the helper prompt. The action explicitly arms the next response, so you receive the AI answer.

- `Ctrl+Shift+Enter` (or `Cmd+Shift+Enter`)
  - Sends the current transcription to the AI.
  - In manual mode, this explicitly arms the next response so the answer is delivered.

Notes
- A tiny audio processing pause is applied when sending via shortcuts to avoid overlapping audio chunks.
- Manual mode suppresses automatic responses; explicit actions (shortcuts above) arm the next response.
